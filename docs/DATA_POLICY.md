# 公開・非公開の分離方針（2026-11-18・初期設計）

- 公開リポジトリ: 動画台帳取得コード、Actions設定、使い方。第三者公開動画のメタデータはGit管理せず、期間制限のあるArtifactで提供。
- 非公開 My-Knowledge: 独自の分析・研究ノート、個人的な戦略検討、成果物、判断履歴。既存ファイル・権限は変更しない。
- Notion: 現在地、実施状況、未解決事項、決定・承認履歴を必要範囲で記録。
- チャンネル動画一覧の取得と、動画の中身の理解・投資戦略の実証は**別工程**。
- 個人のAPIキーはGitHub Actions Secretに格納し、チャット・コード・出力ファイルには含めない。
- フル動画・字幕や有料限定コンテンツの自動取得・再配布はこの初期実装に含めない。
- APIデータは第三者の非承認データなので、30日以内の更新/削除を考慮し、21日保持Artifactを使用。現状は外部公開前のレビュー用ファイル。
- 自動的な実口座売買・投資判断の確定・既存戦略仕様の変更はしない。

## 2026-11-21　公開する出典メモの範囲

通常動画「日本株爆益戦略①」1本を対象に、公開動画台帳ソフトへ場面の出典を付ける試験を行う。Geminiに公開動画URLを渡し、返答を検査して、動画URL、動画内の時刻、選択式の短い話題だけを期限付きのActions成果物にする。モデルによる候補は元動画で再確認する。送信と待機には公開リポジトリの標準ランナーを使う。

非公開の研究ノートには、日本語の発言やチャートと突き合わせた条件・数値・例外・反証を記録する。公開側のコード、ログ、成果物には非公開の分析、APIキー、Geminiの返答全文を含めない。公開側に非公開リポジトリの書き込み権限は付与しない。対象の追加と継続的な一括解析は別途判断する。
